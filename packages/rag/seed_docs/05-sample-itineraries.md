以下时间均按用户日程 09:00–18:00 计算，并标注了不适用的星期。

零门票组合（60 元，覆盖文化与自然，每天可用）：09:00 滨河公园（至 10:30）→ 10:50 老街（至 11:50）→ 12:10 湖畔步道（至 13:25）。费用：餐饮 40 + 门票 0 + 交通 20 = 60 元。

四景点省钱组合（90 元，每天可用）：09:00 滨河公园 → 10:50 老街 → 12:10 古寺 → 13:30 湖畔步道（至 14:45）。费用：40 + 20 + 30 = 90 元。

经典组合（130 元，周一博物馆闭馆不适用）：09:00 滨河公园（至 10:30）→ 10:50 博物馆（至 12:50）→ 13:10 植物园（至 15:10）。

文化为主组合（150 元，周一、周二不适用）：09:00 博物馆（至 11:00）→ 11:20 艺术馆（至 12:50）→ 13:10 滨河公园（至 14:40）。

含观景塔组合（180 元，每天可用）：09:00 滨河公园（至 10:30）→ 10:50 观景塔（至 11:50）→ 12:10 老街（至 13:10）。

雨天组合（150 元，只有公园 1 个户外景点，周一、周二不适用）：09:00 博物馆（至 11:00）→ 11:20 滨河公园（至 12:50）→ 13:10 艺术馆（至 14:40）。

周一雨天组合（200 元）：09:00 海洋馆（至 11:00）→ 11:20 艺术馆（至 12:50）→ 13:10 滨河公园（至 14:40）。周一博物馆、科技馆闭馆，海洋馆和艺术馆照常开放。
